# Security Policy

## Supported Versions

Currently, the `main` branch and the latest designated stable release are supported with security updates. We highly recommend using the latest version available.

## Reporting a Vulnerability

Security is a primary priority for `01cloud-admin` and the broader BerryBytes ecosystem.

If you discover a security vulnerability within this project, please **do not** disclose it publicly via GitHub issues. Instead, please report it privately:

1. Send an email to **security@berrybytes.com** or the relevant maintainer's email with the details of the vulnerability.
2. Include steps to reproduce the issue, the potential impact, and (if applicable) a suggested mitigation.
3. Our security team will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress.
4. If the vulnerability is accepted, we will coordinate with you to publish a secure advisory and a patch.

Thank you for helping us keep our project safe for all users!
